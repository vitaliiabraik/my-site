### Звіт про зміни в CSS (Refactoring Report)

У цій версії файлу стилів проведено рефакторинг коду, покращено структуру, додано адаптивність для зображень та впроваджено компонентний підхід (картки). 

### 🟢 Додано нові селектори та функціонал

* **Глобальне скидання стилів**: Додано правило *, *::before, *::after з box-sizing: border-box для правильного розрахунку розмірів елементів.
* **Селектор .container**: Головний обгортковий блок сайту з max-width: 900px та внутрішніми відступами 15px для мобільних пристроїв.
* **Компонент .card**: Новий блочний елемент для контенту з напівпрозорим фоном, рамкою, внутрішніми відступами 20px та тінню.
* **Селектор .gallery**: Додано адаптивну сітку на базі CSS Grid (grid-template-columns: repeat(auto-fit, minmax(200px, 1fr))) для зображень.
* **Ефект для зображень img:hover**: Додано плавне збільшення картинок (transform: scale(1.03)) та підсвітку рамки зеленим кольором при наведенні.

### 🟡 Змінено та оптимізовано

* **body**: 

  * Оновлено посилання на фонове зображення (background-image).
  * Прибрано max-width: 800px та margin: 0 auto (цю роль тепер виконує .container).
  * Змінено margin з 0 auto на 0.
* **p, li**: Тепер стилізуються всередині картки (.card p, .card li). Їм прибрано індивідуальний чорний фон (background: transparent) та внутрішні відступи для уникнення «ефекту накладання».
* **h1, h2, h3**: Прибрано верхній відступ (margin-top: 0), оскільки контейнер картки вже має власні падінги.
* **ol**: Зменшено прозорість фону, змінено внутрішні відступи та колір рамки (#333 замість #444).
* **table**: Зменшено товщину зовнішньої рамки до 2px, змінено відступи. Для th, td додано внутрішні відступи 10px та явний фон для комірок rgba(0, 0, 0, 0.5).
* **img**: Повністю перероблено під адаптивність. Прибрано фіксовані відступи 10px 5px, додано width: 100%, height: 180px та object-fit: cover. Рамку зменшено з 4px до 3px.
* **a (Посилання)**: Зменшено верхній відступ з 20px до 15px.

### 🔴 Вилучено

* Пряме завантаження @import перенесено нижче блоку скидання стилів.
* Вилучено жорсткі індивідуальні тіні для картинок box-shadow: 4px 4px #000 на користь тіней усього блоку картки або галереї.
